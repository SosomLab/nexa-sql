# UI icon notices

Nexa SQL draws its toolbar, context-menu and activity-bar icons in code. Several of these shapes are traced from the open icon sets listed below. No icon font or image file from these sets is bundled; the shapes are re-drawn as vector masks inside the application.

## Material Symbols / Material Icons (Google)

- Source: https://github.com/google/material-design-icons
- License: Apache License 2.0 — https://www.apache.org/licenses/LICENSE-2.0
- Copyright: Google LLC
- Used for: toolbar and context-menu icons (`toolicons.rs` `mi_*`), activity-bar icons for the object explorer (`database`), project explorer (`folder_open`) and bookmarks (`bookmarks`).
