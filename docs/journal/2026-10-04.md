## 4. 🔧 포맷터 `keyword_case=keep`에서 별칭 `as` → `AS`(10-03 남은 흠 · 개발 세션 수정)

- 수정(`crates/nsql-format/src/layout.rs`): IR에 `Part::AsRaw(String)` **추가**(원문 글자를 든 별칭 AS) — keep 모드이고 원문이 `AS`가 아닐 때만 · 그 밖은 종전 `Part::As`. 렌더 = `As`와 같은 간격 규칙(`as_gap` · 정렬 채움) · 별칭이 뒤따르지 않는 `AS`(`CAST … AS 타입`)는 원문 토큰 기준 · 암묵 별칭에 덧붙이는 AS는 종전대로 `AS`. `As(String)`으로 바꾸지 않은 것 = 확장의 기존 소스·옛 빌드 호환(upper/lower 동작 변화 0). 시험 `keep_case_keeps_alias_as`.
- 확장: `extensions/sdk/samples/sql-formatter-kiros33/src/lib.rs` `AlignKind::As` 판정에 `Part::AsRaw(_)` → **SQL Formatter for kiros33 1.3.3**(버전 3곳 = 개발 세션 · `scripts/ext-build.sh` = 협업 세션 · wasm 189,916 B · sha256 `a7fbfea6…df32` · 확장 시험 10 ✓).
- 확인(협업 세션): CLI `nsql format`(격리 홈 · `format.keyword_case=keep`) = `as`/`As` 보존 · 멱등 · upper 기본 불변 ✓ · 격리 홈 GUI(1.3.3 설치본 배치 · `strict=off` · `open → edit.select_all → format.use:sql-formatter-kiros33 → file.save`) = 보존 + AS 정렬 참여 ✓.
- ⚠ 이 맥 PATH 함정: `/usr/local/bin/cargo`(Homebrew rust 1.98.1 · wasm32 std 없음)가 rustup(`~/.cargo/bin`)보다 앞서 `ext-build.sh`가 `E0463 can't find crate for std`로 실패 → `PATH="$HOME/.cargo/bin:$PATH"`로 재실행. 같은 이유로 이 맥의 앱 빌드도 `rust-toolchain.toml`(stable)이 아니라 Homebrew rustc로 돌고 있었다(CI와 다른 컴파일러).
- 새로 본 기존 흠(upper에서도 같음 · AsRaw 회귀 아님 · 개발 세션 판단 대기): ① 가장 긴 항목이 AS 앞 탭 대신 공백 하나(끝이 탭 경계에 걸린 경우로 추정) ② `force_as`로 붙인 `AS`는 정렬 채움 없음. 재현 = `select a.x as x, b.longer_col As y, a.z from t as a join u b on a.id = b.id;`.
