## 7. 기본 언어 = OS 표시 언어(사용자 09-28 "언어가 있는 경우 설치 시에 해당 언어로 기본 설정, 없는 경우는 영어")

- 판정 = `nsql-i18n::system_lang()`(`syslang.rs` · 외부 crate 0 · 한 번만 묻고 캐시): Windows `GetUserDefaultUILanguage` · macOS `CFLocaleCopyPreferredLanguages` · 그 밖 `LANGUAGE`→`LC_ALL`→`LC_MESSAGES`→`LANG`. 지원 언어(en·ko) 밖이면 영어. GUI를 시작 메뉴·Finder에서 띄우면 `LANG`이 없어 Windows·macOS는 OS API를 쓴다.
- **사용자가 고른 언어가 이긴다**: `ui.lang`은 기본값(OS 언어)과 같아도 고르면 저장하고, 읽을 때도 버리지 않는다(`follows_os_default`) — 한국어 OS에서 한국어를 고른 사람이 OS 언어를 바꿔도 앱은 한국어. `nsql config reset ui.lang` = 다시 OS를 따른다.
- 실측(이 PC = 한국어 Windows · 빈 `NSQL_HOME`): `config get ui.lang` = ko · 도움말 한국어 · `set en` → 파일 저장·영어 · `reset` → ko. 시험 +5(로캘 문자열·LANGID·환경 변수 우선순위·캐시 · 선택 유지/reset) = 627 ✓.
- 기존 사용자: 파일에 `ui.lang`이 없던 사람(= 영어 기본을 쓰던 사람)은 이제 OS 언어를 따른다 · 이미 고른 값은 그대로.
