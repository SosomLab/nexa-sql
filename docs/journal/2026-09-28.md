## 4. 판단 기록

- **`Msg` 도구 오판 → 바로잡음**: 처음 판정은 i18n 파일 안의 `Msg::ALL` 배열(번역 누락 시험용 전체 목록)을 "사용"으로 세어 0이 나왔다. 표·목록·시험 밖 참조만 사용으로 세도록 고친 뒤 62개.
- **효과 없는 설정 키 4개는 계획된 기능**(`db.statement_timeout` = T-90b 등)이었다. 설정 창에서 켜도 아무 일도 없는 것은 사용자를 속이므로 레지스트리에서 빼고, 설계 문서(28·39·47·78)에 ⏸ 표시 · TODO T-249로 재등록 약속.
- **`menu_action`·`worker::spawn`은 그대로**: 앞은 이미 명령 분배표, 뒤는 데이터 보호 불변식이 지나는 DB 스레드라 실서버 통합 시험 없이 구조를 바꾸지 않는다(T-246 · 전제 = CI integration 초록).
- **시험 목적 자산은 남김**: `scripts/`의 탐침·E2E(입력 주입을 쓰는 옛 탐침 `win-badge-probe.ps1`·`memcycle.ps1` 포함 — 사용자 부재 때만) · 자체 시험 기동 명령 · 지난 기능 점검 결과 폴더.
- **청소한 생성물**: `target/llvm-cov-target`(3 GB · 이번 커버리지 빌드) · `packaging/windows/__pycache__`.
- Git Bash 히어독이 파이썬 패치의 백슬래시를 망가뜨림(CLAUDE.md 함정 그대로) → 패치는 전부 스크래치패드의 스크립트 **파일**로.
