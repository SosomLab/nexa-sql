## 2차 (mac) — 병행 개발: 드라이버 · CLI · 최소 GUI

**결정 흡수**: 사용자 "서명 별도 · 나머지 한꺼번에 · GUI 최소 병행" → DP-1~9를 DR-10~18로. 추가 요구 7건은 문서 12·14·15·17·18·19에 흡수(구현 순서는 17).

**드라이버 API 확인**: `~/.cargo/registry`의 `oracle-0.6.3`·`tiberius-0.12.3` 소스를 직접 읽어 시그니처 확정(`Statement::bind/bind_value/is_query/implicit_result` · `RefCursor::query` · tiberius `Client::query/execute` · `ColumnData` 변형). Oracle은 InOut을 VARCHAR2(4000)로 바인드해 문자열로 회수 후 `VarType`으로 강제 — 실서버 검증 전이라 M1 T-4에서 실측 필요. MSSQL은 tiberius에 OUTPUT 회수 API가 없어 `DECLARE @v = @Pn` + 트레일러 `SELECT @v AS [v]` 설계(파라미터로 값 전달 → 리터럴 직렬화·플랜 캐시 문제 회피).

**실기(SQLite)**: `nsql run -c sqlite::memory: examples/sqlite-session-vars.sql` → `EXEC :V_MAX := (SELECT MAX(sal) …)`가 `SELECT … AS "V_MAX"`로 실행돼 520이 흡수되고 `PRINT`·후속 조회 바인드까지 왕복. export json/insert/csv ✓.

**결함 4건**: ① 줄 기반 분리기가 한 줄 다중 문장을 잃음 → 오프셋 기반으로 재작성 ② 블록 EXEC 시작을 개행 위치로 넘겨 본문이 빔 ③ `?` 방언 `:V := expr`이 `CALL`로 래핑 ④ OUT 흡수가 이름 목록에 갇혀 별칭 컬럼을 놓침 → 1행 트레일러의 모든 컬럼 흡수.

**GUI**: clip `demo.rs`·`main_win.rs` 이벤트 번역을 참고해 창·워커·그리드 구성. 실행은 워커 스레드(세션은 그 스레드에서 생성 — `Send` 불요), 결과는 채널 + `EventLoopProxy`. 두 `RasterCtx`(UI 본 / 고정폭 본)로 영역별 폰트. 창 실기는 하지 않음(자동 환경) — `--smoke`만.

## 4차 (mac) — 실서버 테스트 구성

로컬 Docker 데몬은 꺼져 있고(Docker 29 설치만) 사용자가 Codespaces + DBMS별 Docker를 택함. devcontainer는 compose 방식(dev + DB 서비스) — `runServices`로 oracle·mssql만 기본 기동, pg/mysql은 프로필. Oracle Free는 gvenzl 이미지(amd64 · `healthcheck.sh` 내장 · APP_USER 자동 생성), Instant Client는 Oracle 영구 링크(basiclite)로 Dockerfile에서 설치. Actions에서는 같은 이미지를 `services:`로 띄우고 러너(Ubuntu 24.04)는 `libaio1t64` → `libaio.so.1` 심볼릭 링크가 필요했다. 통합 테스트는 `NSQL_*_URL` 없으면 [skip]으로 통과해 일반 CI를 막지 않는다. MSSQL `Auto` 변수의 `SQL_VARIANT` 선언은 tiberius 회수가 불안정해 `NVARCHAR(4000)`으로 바꿨다(COUNT 대입은 문자열 "3"으로 돌아오고 엔진이 재추론).

## 5차 (mac) — 실서버 검증

첫 실행: Oracle 2/2 통과(놀랍게도 첫 시도에 — ODPI-C 이름 바인드·VARCHAR2 InOut 회수·`bind_value::<RefCursor>`·GET_LINE 폴링 전부 동작), MSSQL 2/2 실패. 원인은 문서(05 §7)에 적어 둔 바로 그 함정: tiberius가 모든 `query/execute`를 `sp_executesql` RPC로 보내 `#temp`가 반환 시 사라진다. `Route::Batch`(simple_query)를 추가해 파라미터 없는 DDL·세션 문장을 SQL 배치로 보냈다. 둘째는 `SELECT TOP 1 name INTO :V` → `SELECT :V = TOP 1 name`(문법 오류) — 접두 파서 추가. 재실행: 5/5 green. 마지막 `nsql run` 단계는 URL `%40` 미디코드로 sa 로그인 실패 → `ConnectSpec::parse`가 `scheme://` 형식에서만 퍼센트 디코드(SQL*Plus 형식 `u/p@h`는 원문 유지).
