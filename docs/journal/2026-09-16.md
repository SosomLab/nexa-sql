## 6차 (mac) — 세로 정렬(접속 창 그리드·헤더 · 상태줄 Tab 메뉴) · 프로필 이름 변경 저장

- **세로 정렬**(사용자 캡처 비교: Windows 가운데 · 맥 위로 치우침): 접속 창 그리드는 `행 높이 − 8px` 고정 상수, 결과 그리드/상태줄은 `pad/2`·`5px` 고정 — 배율·글꼴과 무관해 Windows 1x 맑은 고딕에서만 맞았다. nexa-ui `DrawCtx::text_center_y`(잉크 기준 · [nexa-ui journal 4차](../../../nexa-ui/docs/journal/2026-09-16.md))로 교체: 접속 창 행·헤더 · 결과 그리드 셀·헤더 · 탐색기 행 · 상태줄 문구·세그먼트. 캡처 정밀 비교는 이 세션에서 이미지를 더 볼 수 없어 사용자 재확인 필요.
- **프로필 이름 변경**(사용자: 목록에서 고른 프로필의 이름을 바꿔 Save → 새 프로필 생성): 패널이 `loaded_name`(fill 시 기록 · New/clear 시 None)을 기억하고, 이름이 바뀌었으면 `PanelAction::Save{rename_from}` → 새 이름 저장 **성공 뒤** 옛 항목 `Vault::remove`(실패 시 옛 프로필 보존) · 폼은 새 이름으로 다시 fill.
- **목록 모드 결과 안내**(사용자: 상세 패널이 닫혀 있으면 Test 결과가 안 보임): `ConnWin::set_note(name, state)` — `set_panel_result`가 패널 상태와 함께 갱신 · 패널이 닫혀 있을 때 목록 오른쪽 아래 한 줄(● + "이름 · 문구" · 성공 초록/실패 빨강/진행 노랑).

## 7차 (mac) — 우클릭 메뉴 항목 간격(결과 그리드 · 상태줄 Tab 메뉴 · 탐색기)

**증상**(사용자 캡처 · 진행 확인 요청): 맥에서 메뉴 항목 간격이 Windows와 다르다(겹쳐 보임).
**원인**: `ContextMenu`는 행 높이·여백을 `set_scale`로 받은 배율로 계산하는데, 결과 그리드·상태줄 Tab 메뉴·탐색기 메뉴는 열 때 `set_scale`을 **호출하지 않았다** → 맥 2x에서 배율 1.0으로 계산돼 행 26px(논리 13px)·여백 절반. Windows 100%는 배율 1이라 드러나지 않았다(접속 창·파일 대화상자는 호출하고 있었다). 부수: 그리드 메뉴는 고정폭 글꼴 패스에서 그려져 다른 메뉴와 글꼴이 달랐다.
**조치**: `Grid::open_menu(x, y, scale)` + `set_scale` · `status_menu.set_scale(self.scale)` · 탐색기 동일 · 그리드 메뉴는 `Grid::paint_menu`로 분리해 UI 글꼴 최상위 패스에서. 앞선 6차 잉크 기준 정렬과 합쳐 Windows와 같은 행 높이·글자 위치.
