- `cargo test --workspace --all-features` = **19/19**(base32 4 · date 1 · format 6 · machine 2 · request 1 · types 2 · verify 3). 의존 MSRV 확인: ed25519-dalek 2.2.0 = 1.81 · curve25519-dalek 4.1.3 = 1.60 → `rust-version = "1.82"` 그대로 충분.

### 7-2. 문서 사이 어긋남 하나(결정 대기 · 사용자에게 보고)

`nexa-license`의 서명 코드 위치가 문서마다 다르다 — **25 §11-1(09-14)·README·lib.rs** = "공개 라이브러리는 검증 전용 · `issuer` feature 삭제 · 서명은 비공개 저장소만" vs **25 §12-1·§12-8(09-27 확정용 제안)** = "`nexa-license` `features = ["issuer"]` 뒤에 sign".
