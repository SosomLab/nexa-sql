## 12. §11 ①② 착수(사용자 "1, 2 진행") — keygen은 **사용자 손**으로

- 발급기에 `rekey`(봉투 암호 변경 · 같은 키쌍 · `.pub` 같이 · E2E)를 더했다(nexa-license main) — 첫 암호를 누가 정했든 운영자가 바꿀 수 있게.

  ```
  T=~/Projects/kiros33/nexa-license/target/release/nexa-license-tool
  mkdir -p ~/nexa-issuer && chmod 700 ~/nexa-issuer
  $T keygen --out ~/nexa-issuer/root-v1.key --id root-v1            # 암호 두 번(프롬프트)
  $T keys-rs ~/nexa-issuer/root-v1.key.pub --out ~/Projects/kiros33/nexa-license/crates/nexa-license/src/keys.rs
  ```
