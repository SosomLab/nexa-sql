## 4차 (mac) — Oracle Instant Client 설치·설정(실기)

사용자 질문 두 건("mac 설치 방법" → "전 패키지를 한 폴더에 · CLI 포함" → "폴더 위치·이름 추천")을 [20 §5](../20-testing-codespaces.md)에 Windows 정리와 같은 구조로 정리하고 `scripts/install-instantclient-mac.sh`로 자동화했다.

**조사 실측**: ① Intel 최신 = **19.16**이고 버전 경로에 **zip이 없다**(DMG만) · ARM64는 23.26.2 zip 있음 ② 버전 없는 `instantclient-*-macos.zip`은 **19.8로 낡음**(mix 위험) ③ `otool -l sqlplus` → `LC_RPATH = @executable_path/` = **한 폴더에 모두 풀면 DYLD 없이 동작**(사용자 요구와 정확히 맞음) ④ Oracle `install_ic.sh`는 대상 경로가 `~/Downloads/instantclient_19_16`으로 박혀 있어 쓰지 않고 직접 복사.

**설치 실측(이 Mac · Intel i9 · macOS 26)**: `~/Oracle/instantclient_19_16` 6패키지 255MB · `sqlplus -V` = 19.16 · `~/lib` 링크 8개 · `nsql run -c oracle://…`이 DPI-1047 없이 **ORA-12541**(로컬 리스너 없음)까지 도달 = 클라이언트 로드 성공. 폴더 규칙은 **버전 폴더 + 버전 없는 심볼릭 링크**(`~/Oracle/instantclient`)로 정해 `.zshrc`를 버전과 분리했다.

**남은 것**: 사내 Oracle(192.168.0.55/58)로 `sqlplus`·`nsql run` 실접속 — 사용자 네트워크에서만 가능.
