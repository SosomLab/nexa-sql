## 14차 (win) — 신호등 주기 갱신·즉시 갱신 · 실행 전 빠른 판정 · 워커 패닉 격리 · 행 Test/Connect 버튼 · 패널 상태 1개

**요청**(사용자 · 연속 7건): ① 연결 목록 1분마다 갱신 · 실패하면 **그때부터 횟수 누적** ② 재시도 시간·최대 횟수 설정 ③ 접속 창이든 SQL 실행이든 접속 실패가 확인되면 **그 서버 즉시 갱신** ④ 한 탭/쿼리의 접속 장애가 전체에 번지지 않게 **영향도 분리** + 끊긴 서버에 쿼리할 때 **최대한 빨리 정상/비정상 판정** ⑤ A 서버 Test 중 B 클릭 → A 다시 클릭하면 Testing 표시가 사라짐 → "한 번에 상태 1개" ⑥ 서버 접속이 안 되는데(ORA-12170) 계속 초록 ⑦ 행에 Test/Connect **아이콘 버튼** — Test 결과는 버튼 표시만 바꾸고 기능 유지(재시도 가능) · Connect 성공 = 활성 탭에 적용 + 자동 닫기 · 탭 0개면 새 탭. + `SNOPDB_19c` 프로필 추가(`nsql conn add … --no-prompt` · `conn test` 0.9s OK — 이후 사용자 환경에서 도달 불가로 바뀜 = ⑥의 원인: 창 열 때 1회 판정이 굳어 있었음).
**구현**(`probe.rs` · `conn_win.rs` · `worker.rs` · `main.rs` · settings · i18n):
- **정책** `ProbePolicy { enabled, max_retries, timeout, retry_delay, interval }` ← 설정 `probe.interval`(기본 60 · 5~3600) · `probe.retry_delay`(기본 2 · 1~600) 신설 · `max_retries`/`timeout` 기존. `backoff(attempt, base, cap)` = base×2^(n-1) · **상한 = 주기**.
- **주기 갱신**: `apply()`가 Up이면 `attempts=0 · next=now+interval`, 실패면 `attempts+=1` · `≤max_retries`면 지수 백오프, 넘기면 주기(누적은 계속). 창 열 때 `probes.clear()` 대신 `poke(now)`(누적 보존). 창 닫히면 주기 멈춤.
- **즉시 갱신** `ConnWin::note_failure(name)`: Connect/Test 실패(`ConnOutcome`) · 실행 `RunEvent::Error`가 `is_connection_error(code, msg)`(ORA-00028/01041/03113/03114/03135/03150/12170/12514/12541/12543/12545/12560 + refused/reset/timed out/TDS/socket/os error 10054·10060·10061 문구)일 때 활성 프로필(`mark_connected`가 기억)을 창이 닫혀 있어도 프로브 큐에 넣는다. 대상 집합 밖 프로필도 이번엔 묻는다.
- **실행 전 빠른 판정**: `Cmd::Run { src, preflight: Option<Duration> }` — UI는 활성 프로필 신호등이 Up이 아니면 `probe.timeout`을 실어 보내고, 워커는 직전 실행이 접속성 오류였으면(`suspect`) 스스로 2s로 켠다. `probe_once(host, port)`가 Up이 아니면 `Msg::ErrServerUnreachable`("{host}:{port} · 빠른 판정 N ms · 쿼리 미전송")로 즉시 실패 — 드라이버 타임아웃(OCI 수십 초)을 기다리지 않는다. 접속 성공/끊기에 `active_ep`·`suspect` 갱신.
- **패닉 격리**: 워커 루프의 명령 처리를 `catch_unwind(AssertUnwindSafe)`로 감쌈 — 드라이버/엔진 패닉 시 세션·연결 설명 버림 · `Msg::WkPanic` 오류 + `Disconnected` + done 신호로 UI `busy` 해제 · 스레드 생존. (탭별 세션 분리는 T-54 그대로 — 지금은 모든 탭이 한 세션이라 "전체 영향 없음"의 나머지 절반은 거기서.)
- **패널 상태 1개**: `App.panel_op: Option<(프로필명, ConnState)>` — Test/Connect 시작 시 기록 · 결과는 `set_panel_result(name, st)`(그 프로필이 폼에 떠 있을 때만 상태줄 갱신 · 기록은 항상) · `LoadProfile`이 같은 이름이면 복원, 다르면 Idle · Disconnect에 비움. 결과 이름은 `panel_op_name()`(폼의 현재 이름이 아니라 **작업이 시작된 이름**).
- **행 버튼**: 고정 아이콘 열 3개(신호등 · Test 고리 · Connect 삼각형 · `ICON_COLS`) · 헤더에 흐린 아이콘 · 호버 바탕 · 클릭 = `ConnWinAction::TestProfile`/`Login`(더블클릭 판정 제외 · 선택만 이동). `TestMark {Testing, Ok, Failed}` = 고리 색(노랑/초록/빨강) + 가운데(점/채운 점/막대) · 버튼 모양·기능 불변. `test_profile()`은 폼을 건드리지 않고 vault 스펙으로 `Cmd::Test` · `busy`면 거부. Connect 성공 시 `Editors::ensure_tab()`(탭 0개면 새 탭) 뒤 `set_conn_desc`.
**실측**: 테스트 13(probe 5 · backoff/누적/분류기) · clippy 0 · GUI 실기(자동 클릭 캡처): SNOPDB_19c Test → 노랑 → 빨강 막대 · biscm/M4PLAN Test → 초록 점 · 신호등 SNOPDB_19c 빨강(창 열 때 즉시) · 재시도 2s 후 노랑→빨강.
