## §5. T-178 FK 참조 컬럼 `ref_cols`(개발 세션)

- 종전 = FK의 참조 쪽 컬럼을 몰라 JOIN 조각·참조 행 보기가 참조 테이블의 PK를 짐작 → 유니크 키를 참조하는 FK에서 틀림.
- nsql-catalog `KeyDef.ref_cols`(키 질의 5열 · Oracle = `all_cons_columns` 2차 조회 · SQL Server·PG·MySQL = 5열 · SQLite = `pragma foreign_key_list`의 `to`) → 메타 `KeyEntry.ref_cols` · `NewDetail.keys` 5-튜플.
- 소비자 = JOIN 조건 조각 `fk_join_conds`(참조 컬럼 우선 · 유니크 키 참조도 맞음 · [76 §16](../76-intellisense-and-outline.md)) · 셀 메뉴 참조 행 보기 `follow_fk`(같은 규칙) · 상세 카드·탐색기 FK 라벨 `→ 테이블 (컬럼)`([86](../86-object-details-panel.md)) · Generate SQL 비-MSSQL `REFERENCES t (cols)`.
