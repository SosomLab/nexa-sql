### 설계 · 구현 = [52 세션 모드](../52-session-modes.md) · **DR-34**

- **`sessions.rs`(신규)**: `Sess` = 워커(스레드·Runner·DB 세션) + 그 세션의 실행 상태 **전부**(busy · aux · tx_pending/txlog · run_editor/run_tab/… · run_toast · key_cache · status · idle). `App.sess` = 활성 탭의 세션 · `parked` = 나머지 · 활성 탭이 바뀌면 `mem::swap` 1회(`sync_sess`) · 잠든 세션의 이벤트는 `with_sess`로 잠시 앞에 꺼내 **같은 `drain_events`** 로 처리 → main.rs의 세션 상태 참조 328곳을 `self.sess.*`로 기계 변환만 하고 다중 세션이 됐다.
- **통제 단일화**: `Sess::blocked() = busy ∨ aux>0` · 문지기 `gate_open()` · 화면 `sync_gate()`/`gate_view`. 전수 점검(`worker.send` 26곳 · 52 §3-1)에서 **무통제 5건 발견·수정** — 실행 중 추가 페치/전체 조회/건수/키 조회가 큐에 쌓임 · Commit/Rollback이 실행 뒤에 줄 서서 조용히 실행 · Explain이 직전 실행의 결과 탭으로 · 접속 창이 활성 탭 세션의 busy를 봄 · 실행 앞에 끼운 재접속의 `done`이 busy를 일찍 풂(`skip_done`). 그리드는 `session_blocked`면 자동 페치 요청 자체를 만들지 않고 도구줄(⇊·Σ·새로고침)을 흐리게 · ■만 활성.
- **전용 세션**: 실행 직전 `connect_intent`(파싱만) → `placement` → `NewPrivate`(새 워커 · 탭 표식 · 옛 결과 `more=false`) / `Retarget` / `ClosePrivate`(미커밋 확인 → 세션 거둠 → 공유 복귀) / `Run`(공유 탭은 처음 실행한 연결에 묶임). `CONNECT 프로필` · `CONNECT "oracle://u/p@h:1521/svc"` · 짧은 스킴 `oracle:h:1521/svc`(자격 없음 → 같은 대상 프로필이 **하나뿐이면** 자격을 빌림 `worker::fill_credentials`) · `sqlite:경로` · 따옴표. 설정 `session.private_connect`(끄면 종전 = 공유 세션 교체).
- **접두 조사(52 §5)**: 문장 첫머리가 `CONNECT`/`DISCONNECT`인 서버 SQL은 Oracle·MSSQL·PG·MySQL·SQLite에 없고, DB2/Informix/ISO는 뜻이 같다 → **접두 불필요**. 유일한 구멍 = 선택 실행으로 잘린 `CONNECT BY …` 조각 → 가드(`is_connect_by`) · 짝 별칭 `:disconnect` 추가.
- **공유 연결 N개**: `login_plan`(Use 중복 금지 · Busy · Recycle · New · Limit `session.max_shared` 4) · 활성 공유 연결 `default_shared` · `tab_bind` · 공유 연결이 둘 이상이면 공유 탭에도 표식(중립색) · **툴바 Disconnect ▾**(활성화/해제/모두 해제 · 대상 하나면 바로) · 해제 시 탐색기 동반 종료 · 묶인 탭은 끊김 표식 · `reap_shared`.

- **탐색기 = 한 트리처럼 이어 붙이기(사용자 캡처 "수평 분할된 패널처럼 보인다 → 1번째 서버 정보 끝에 연결")**: 칸 높이를 깎아 각자 스크롤하던 `stack_heights` 폐기 → 각 서버 트리를 **내용 전체 높이**로 연달아 놓고 `ExplorerSet`이 **공용 스크롤 하나**(`scroll` + 오버레이 `ScrollBars`)를 갖는다. `Explorer::set_clip`(공용 뷰포트)로 그리기·히트 테스트를 보이는 부분만 · 키보드 이동은 `selected_span`으로 공용 스크롤이 따라감 · 휠/스크롤바 끌기는 묶음이 먼저 처리.
- **자동 맞춤을 더 딱 맞게(사용자 "헤더와 값을 포함해서 더 Tight하게 · Pass는 헤더만 보이면 된다")**: 필요한 폭 = `pad` + max(헤더 이름[+ 지금 달린 정렬 배지], 값) + `pad/2` + 1px. 종전엔 정렬 배지 자리(`" ▲9"`)를 늘 더했고 오른쪽 여백도 `pad`였다 → 헤더·행의 오른쪽 클립을 `pad/2`로 같이 줄여 식을 하나로. 비밀번호 열 = 체크 상자 < "Pass"라 헤더 폭이 결정.
