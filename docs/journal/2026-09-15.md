## 4차 (win · 야간 자율 계속) — Oracle 라이브 로그 모니터(T-71 1차)

**구현**([32 §2](../32-server-messages-and-live-log.md)): 설정 `oracle.live.source`(off · **session** 기본 · table) · `oracle.live.interval_ms` 1000 · `oracle.live.table/ts_col/text_col` — 접속 시 워커가 편집기 세션 **SID**(`SYS_CONTEXT('USERENV','SID')`)를 `ConnOutcome::SessionId`로 알리고, 실행 시작(`run_sql`/`run_explain`)부터 **busy 동안** 탐색기 메타 세션이 폴링(`Req::Live` · `live_query`): session = `V$SESSION.client_info/action/module WHERE sid` (바뀐 줄만) · table = `SELECT TO_CHAR(ts) , text FROM <table> WHERE ts > :since ORDER BY ts`(첫 폴링은 서버 `SYSTIMESTAMP`를 기준점으로 · 식별자 검사) → 로그 창 `[live] …`(LogKind::Output) + 그리드 메시지. 실행이 끝나면 마지막 1회. 이벤트 루프 대기 시각에 폴링 시각을 합친다(`live_tick`). CLI `--live`는 후속.
**실서버(mechanism)**: biscm 임시 `NSQL_IT_LIVE`(DBMS_APPLICATION_INFO.SET_CLIENT_INFO 'step i of 4' + `DBMS_SESSION.SLEEP(1)` · DBMS_LOCK은 권한 없음) — 두 번째 세션의 `V$SESSION` 폴링으로 step 1→4→done이 실시간으로 보임(BISCM 계정 V$SESSION 조회 가능) → 삭제. GUI 폴링 경로는 빌드·clippy 통과(사용자 실기 ⏳).

**확인**: 현재는 4종 모두 정적 링크(`nsql-drivers` feature) · 플러그인은 설계만(DR-24 · T-27~31 미착수).
**실측(release)**: `nsql --version` 첫 실행 343ms(콜드 · 프로세스 생성 포함) · `sqlite::memory:` 실행 24ms · GUI 사설 메모리 8.5MB(워킹셋 29MB · 디버그) · exe 5.4MB/4.3MB · 드라이버 전역 초기화 없음(tokio 런타임·ODPI-C = 첫 접속).
**결론(DR-29)**: 정적 링크는 기동·메모리·속도 비용이 없다(요구 페이징) → 내장 4종은 그대로. 확장이 필요할 때의 전송은 **프로세스가 아닌 in-process cdylib(C ABI · 지연 dlopen · IPC 0)**로 확정하고 T-27을 개정 · [22 §0](../22-driver-extensions.md) 비교표.

## 8차 (win) — 환경 설정 창(T-39 1차) · 접속 해제 툴바 · 메뉴 글꼴 · 탐색기 셰브론

**요청**(사용자): 풀다운 메뉴와 무관하게 설정 정보를 모은 **Preferences 화면**(다른 앱 참고 · 검색 · 트리 · 스크롤 · 카테고리별 리스트/콤보/그리드 등 적합한 형태) · 연결 버튼 상시 + **연결 해제 툴바**(탭 접속 시만 활성) · 풀다운 메뉴 글꼴 확대 · 확장/축소 글리프를 nexa-dir2 파일 그리드처럼(내용 없으면 표시 안 함).
**구현**
- **환경 설정 창 `prefs_win.rs`**(Edit ▸ Preferences… · Ctrl+, / ⌘, · 소유 창 920×640): 상단 **검색**(키·라벨·설명·카테고리 부분 일치 · 전 카테고리 횡단) · 왼쪽 **트리**(nexa-ctl `TreeView` · `CATEGORY_TREE` 그룹 ▸ 카테고리 · 그룹 선택 = 그 그룹 전체) · 오른쪽 **카드 목록**(스크롤 · 오버레이 바): 라벨(굵게)+키+설명(단어 줄바꿈)+컨트롤 — Bool = `Switch` · Choice/Lang = `Combo`(드롭다운은 맨 뒤 층) · Int/Text = `TextBox`(즉시 정규화 · 틀리면 카드에 허용값 표시 · 저장 안 함) · 색 = [선택…](색 설정 창) · 단축키 = [캡처…](단축키 창) · 기본값 표시 · 바뀐 카드 = 왼쪽 강조 막대 + [초기화] · 하단 **고급** 스위치(비노출 `HIDDEN` 포함). 값은 바꾸는 즉시 저장 + **즉시 반영**(`apply_setting`: 테마 · 언어 · hover/눌림 색 · 페이드 ms · 스크롤 반전 · 탐색기 표시/폭 · 그리드 행번호/스크롤 · 편집기 줄번호/안내선/공백 · 탭 툴팁 · 로그 형식 · `key.*` 키맵 · 글꼴 크기) — 나머지는 "다음 시작부터 적용" 상태줄.
- **접속 해제 툴바**: nexa-ui `Toolbar` 항목 `enabled`(`set_item_enabled` · 비활성 = 흐림+반투명 · hover/클릭 없음) · `toolicons::disconnect`(플러그·소켓 벌어짐) · `conn.disconnect`(메뉴 Run · 팔레트 · `key.conn.disconnect`) · 접속 성공/해제에 따라 활성 동기화 · 접속 버튼은 항상 활성(툴팁 "Connect").
- **메뉴 글꼴**: `ui.menu_font_size`(기본 17 · Appearance) — 메뉴바를 별도 글꼴 컨텍스트로 최상위 층에 그림 · 메뉴 높이 = 글꼴+11.
- **탐색기 셰브론**: nexa-ctl `draw_chevron_right/down`(nexa-dir2 파일 그리드 부품) · 읽은 뒤 자식이 없으면 셰브론 없음.
**검증**: 워크스페이스 빌드·clippy·테스트 green · GUI 부팅. 실기(카드 배치·콤보·검색)는 사용자 ⏳.

## 9차 (win) — 설정 창 오른쪽 클릭이 왼쪽 트리를 선택하던 결함 · 마우스 라우팅 규칙

**요청**(사용자 캡처): "좌측이 아니라 우측을 클릭했는데 좌측 메뉴가 클릭됨 — 다른 앱에서도 발생 · 규칙에 넣어라".
**원인 2겹**: ① nexa-ctl `TreeView::row_hit`가 **y만** 보고 행을 골랐다(x 범위 미검사) ② 설정 창이 MouseDown을 트리에 무조건 전달했다.
**수정**: ① `row_hit` = bounds x·y 둘 다(테스트 `click_outside_horizontal_bounds_is_ignored`) ② `prefs_win.rs route(bounds, focused)` — 마우스/휠은 커서 아래 컨트롤에만 · 키는 포커스 컨트롤에만. **규칙** CLAUDE.md §3 "마우스 라우팅 규칙" + 메모리 `mouse-routing-rule`. 탐색기 루트 = 프로필 이름 + host:port(8차 후속).

## 10차 (win) — 설정 JSON 편집(외부 프로그램 + 저장 감시 즉시 반영) · 설정 창 스플리터/세로 우선 분할 · 탐색기 글꼴

**요청**(사용자): 설정을 JSON으로 편집(계층 = object) · 저장하면 앱이 감지해 바로 UI 반영 · 지금은 .json 연결 외부 프로그램으로 열고, 편집기가 충분해지면 내장 편집기로 여는 설정도 고려(설계·할일) · 탐색기 셰브론이 글꼴과 같이 커지는가 · 탐색기 글꼴 = 풀다운 기본 글꼴 · 설정 창 목록/내용 사이 스플리터(clip처럼 서서히 진해짐) · 검색은 왼쪽 열 상단(세로 우선 분할).
**구현**
- `nsql-settings::json`(외부 crate 0 · 자체 JSON 파서/작성기): `to_json` = 키 `a.b.c` → `{"a":{"b":{"c":…}}}` 객체 계층(Int = 숫자 · Bool = true/false · 그 외 문자열 · `HIDDEN` 포함 · `_comment`) · `Settings::import_json` = JSON에 **있는** 키만 적용(없는 키 유지 · 모르는 키/틀린 값은 보고) · `export_json` = `settings.json`(settings.conf 옆). 테스트 2(파서 유니코드·대리쌍 · 내보내기/부분 가져오기).
- GUI: Edit ▸ **Edit settings as JSON…** · 설정 창 [JSON 편집…] → 내보내고 OS 연결 프로그램으로 열기(`cmd /C start` · `open` · `xdg-open`) → **1초 폴링 감시**(mtime · 연 뒤에만) → 저장되면 `import_json` → 바뀐 키만 `apply_setting` 즉시 반영 + settings.conf 저장 + 설정 창 갱신 + 상태줄/로그 "n changed · unknown/invalid · 다음 시작". 설정 `settings.json_editor = external|builtin`(builtin은 T-74 파일 저장 뒤 편집기 탭으로 · 지금은 external 대체 안내 · **T-76**).
- CLI: `nsql config export-json [file|-]` · `import-json <file>`(바뀐 키·무시 키 출력) — 실측 왕복 ✅(ui.font_size 16 적용 후 reset).
- 설정 창: **세로 우선 분할** — 왼쪽 열 = 검색(위)+트리(아래) · **스플리터**(드래그로 폭 160~ · ColResize 커서 · hover 시 `IntentFade`로 서서히 진해지는 손잡이 = clip 부품) · 오른쪽 = 카드 맨 위부터.
- 탐색기: `explorer.font_size`(기본 17 = 메뉴 글꼴) 별도 글꼴 층 · 행 높이·셰브론·칩이 글꼴 높이에 비례(글꼴을 키우면 같이 커진다 — 사용자 질문 답).

## 11차 (win) — 접속 창 모달

**요청**(사용자): 연결 창을 모달로.
**구현**: 접속 창이 열려 있는 동안 ① Windows = `EnableWindow(main, FALSE)`(`winfocus::set_enabled` · user32 FFI · crate 0 — 메인을 클릭하면 표준 모달처럼 접속 창이 깜빡이며 앞으로) ② 호스트 가드 = 메인 창의 키/마우스/휠/IME 이벤트를 버리고 접속 창에 포커스(macOS/Linux도 같은 효과). 열림/닫힘 전환은 `sync_conn_modal`(열 때 즉시 · 매 프레임 확인 — 접속 성공 자동 닫힘·X·Esc 모두) · 닫히면 메인 다시 활성 + 포커스. 부팅 시 접속 창이 열리는 흐름도 그대로 모달.
