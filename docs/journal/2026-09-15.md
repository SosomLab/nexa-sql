## 4차 (win · 야간 자율 계속) — Oracle 라이브 로그 모니터(T-71 1차)

**구현**([32 §2](../32-server-messages-and-live-log.md)): 설정 `oracle.live.source`(off · **session** 기본 · table) · `oracle.live.interval_ms` 1000 · `oracle.live.table/ts_col/text_col` — 접속 시 워커가 편집기 세션 **SID**(`SYS_CONTEXT('USERENV','SID')`)를 `ConnOutcome::SessionId`로 알리고, 실행 시작(`run_sql`/`run_explain`)부터 **busy 동안** 탐색기 메타 세션이 폴링(`Req::Live` · `live_query`): session = `V$SESSION.client_info/action/module WHERE sid` (바뀐 줄만) · table = `SELECT TO_CHAR(ts) , text FROM <table> WHERE ts > :since ORDER BY ts`(첫 폴링은 서버 `SYSTIMESTAMP`를 기준점으로 · 식별자 검사) → 로그 창 `[live] …`(LogKind::Output) + 그리드 메시지. 실행이 끝나면 마지막 1회. 이벤트 루프 대기 시각에 폴링 시각을 합친다(`live_tick`). CLI `--live`는 후속.
**실서버(mechanism)**: biscm 임시 `NSQL_IT_LIVE`(DBMS_APPLICATION_INFO.SET_CLIENT_INFO 'step i of 4' + `DBMS_SESSION.SLEEP(1)` · DBMS_LOCK은 권한 없음) — 두 번째 세션의 `V$SESSION` 폴링으로 step 1→4→done이 실시간으로 보임(BISCM 계정 V$SESSION 조회 가능) → 삭제. GUI 폴링 경로는 빌드·clippy 통과(사용자 실기 ⏳).

**결론(DR-29)**: 정적 링크는 기동·메모리·속도 비용이 없다(요구 페이징) → 내장 4종은 그대로. 확장이 필요할 때의 전송은 **프로세스가 아닌 in-process cdylib(C ABI · 지연 dlopen · IPC 0)**로 확정하고 T-27을 개정 · [22 §0](../22-driver-extensions.md) 비교표.

## 19차 (win) — 드래그 미시작 결함(더블클릭 시간 판정) · 붙여넣기 탭→공백 · 탭별 들여쓰기 · Ctrl+D 다중 선택 · Alt+Shift 열 선택 · 선택 행 번호 표시

**요청**(사용자): ① 마지막 줄 `;` 뒤를 클릭해 드래그하면 `;` 앞이 선택된 채 드래그가 안 됨("다른 이벤트가 끼어드는 것 같다") ② 공백 들여쓰기 탭에 Tab이 든 텍스트를 붙여넣으면 설정 폭(2/4/8)의 공백으로 · 파일(탭)마다 Tab/Space 설정이 다를 수 있음 ③ Ctrl+D = Sublime과 동일 ④ Alt+Shift 드래그 = 열 선택 모드(다중 커서 · 여러 행 선택 시 행 번호에 선택 표시).
**원인·구현**
- ①은 끼어든 이벤트가 아니라 **더블클릭 판정에 시간이 없던 것** — 같은 캐럿 인덱스를 다시 누르면 얼마나 지났든 2연속 클릭 = 단어 선택(`select_word_at`)이 되어 `dragging`이 켜지지 않았다. `TextBox`에 `last_click_at`(Instant) + `DOUBLE_CLICK_MS = 500`으로 체인을 시간 제한(`click_chain_alive`). 테스트 `slow_second_click_starts_drag_not_word_select`.
- ② `TextBox::paste`가 `indent_spaces`면 탭 문자를 **캐럿 열부터 다음 탭 정지까지의 공백**으로 편다(`expand_tabs` · 줄마다 열 재계산 · 선택 대체는 선택 시작 열). 탭 들여쓰기 탭은 그대로. 테스트 `paste_expands_tabs_when_indent_spaces`.
- ② 탭별 들여쓰기: `Editors.indents: Vec<Option<(u8,bool)>>` — 상태줄 팝업은 **활성 탭만**(`set_tab_indent` · Sublime 관례), 설정(`editor.tab_size`/`indent_spaces`)은 기본값 = 재정의 없는 탭 + 새 탭. 상태줄 세그먼트는 활성 탭 값. 탭 폭 렌더링도 탭마다 — `TextBox::paint` 진입에서 `nexa_gfx::text::set_tab_cols(self.tab_size)`를 주입(측정·그리기·캐럿 동일).
- ③ **다중 선택 모델**(nexa-ctl `EditState.extra: Vec<(anchor, caret)>`): `regions()`/`carets()`/`add_selection`/`set_regions`/`clear_multi`/`selected_text_multi`. 삽입·삭제·Backspace·Delete·붙여넣기·잘라내기는 `edit_regions`가 **전 구간에 앞에서부터 누적 반영**. ←/→는 모든 캐럿 이동(Shift = 확장), 클릭·세로 이동·Home/End·전체 선택은 하나로 접힘, Esc = 접기. 되돌리기 스냅샷에 포함. `TextBox::select_next_occurrence` = 선택 없으면 캐럿 밑 단어 → 있으면 같은 문자열의 다음 출현 추가(끝에서 처음으로 순환 · 중복 제외). 명령 `edit.expand_selection`(Ctrl+D) · `edit.select_all_occurrences`(Ctrl+⇧D · 전부) · Edit 메뉴·팔레트·단축키 창(`key.*`). 상태줄 Ln/Col 자리에 `N selections`.
- ④ **열 선택**: 호스트가 `ModifiersChanged`로 Alt+Shift를 `Editors::set_column_mode`에 밀어 주고, `TextBox`는 그 상태에서 MouseDown = 열 드래그 시작(`col_anchor`), MouseMove마다 시작점~현재점 사이 **모든 표시 행에 같은 x 구간**(`column_regions` · 픽셀 기준이라 비례 폰트도 자연) → `set_regions`. 폭 0 = 행마다 캐럿(다중 커서). 페인트는 구간 전부 반전 + 캐럿 전부 + **선택에 걸린 행의 줄번호 거터를 선택색으로**(사용자 이미지 2). 테스트 `alt_shift_drag_makes_column_selection` · `ctrl_d_selects_word_then_next_occurrence` · edit.rs 3종.
**조사 진행**: DBeaver SQL 편집기 색 배치(설치본 jar `plugin.xml`·다크 CSS·사용자 워크스페이스 prefs = 오버라이드 0) · Golden 색/선택 모드(에이전트 진행 중) → [35](../35-editor-colors-reference.md)에 정리 예정.
**다음**: 파일 열기/저장/다른 이름으로(T-74 · 자체 대화상자 · nexa-ui docs/20 F-1~F-6).

- ② `EditMenuDecor`(nexa-ctl `set_edit_menu_decor` · thread_local) — 복사/잘라내기/붙여넣기/전체 선택 아이콘 + 키맵 단축키 문구(`apply_menu_decor` · 키맵 변경 시 갱신). 메뉴 아이콘 7+3종 = 코드 마스크(`toolicons::mi_*`).
- ③ `TextBox` 선택 반전: 줄 넘김 행은 **글자 끝 + 한 칸**까지만(전폭 아님 · Golden식).
- ④ 툴바 hover/pressed 배경 제거 — 아이콘 accent 색 + 눌림 1px만.
- ⑤ 탐색기: 부분적으로 잘린 마지막 행은 셰브론·아이콘을 그리지 않는다(도형은 클립이 없었다).
- ⑥ `findbar.rs` 재작성 = **플로팅 패널**(편집기 오른쪽 위 · 본문을 밀지 않음): `›` 펼침 토글 → 바꾸기 줄 · `Aa` · **`ab` 단어 단위**(호스트 검색에 경계 검사) · `n of m` · ↑ ↓ × · 바꾸기/모두. 레이아웃은 편집기 배치 뒤 `set_bounds(editor_bounds)`.
- ⑦ `activity.rs` = **활동 막대**(48px · 아이콘 24px): 위 = 패널 버튼(오브젝트 탐색기 — 클릭 = 토글 · 활성 = 왼쪽 2px 띠) · 아래 = 동작(접속 창 · 환경 설정). 탐색기는 막대 오른쪽에 붙고 `explorer.visible`과 동기. (패널이 하나뿐이라 "다른 버튼 = 창 이동"은 파일 검색 패널(T-81a)부터.)
- ⑧ nexa-dlg `FilePicker::set_extra(라벨, 항목, 선택)` — 하단 버튼 줄에 **부가 콤보**(확인 왼쪽) · `extra_value()`. nexa-sql = **인코딩** 콤보(열기: 자동 감지/UTF-8/UTF-8 BOM/UTF-16 LE/BE · 저장: 4종) · 자동 감지 = BOM · 탭별 인코딩 기억(`encs`) · 저장 시 그 인코딩으로(BOM 포함). EUC-KR/CP949는 표 내장 뒤(T-79). **검토 답**: 자체 대화상자는 복합 컨트롤이라 하단 줄 확장이 같은 코드로 세 OS 동일 — 네이티브였다면 OS마다 다른 API/불가(Linux 포털) · 문제 없음.
- ⑨ [36 파일 검색·프로젝트 설계](../36-find-in-files-and-project.md): 활동 막대 두 번째 패널(VS Code Search) · Where 규약(`<current file>`, 절대 폴더, `-` 제외, 콤마) · 범위 3종 · **엔진**(병렬 열거 + 무시 규칙 + memchr SWAR 사전 필터 + 스트리밍 + 취소 + 인덱스/내용 캐시 · `nsql-search` · `nsql grep`) · 프로젝트 파일(메모리 탭 본문 저장 · hot exit) · T-81a~e · D-55~57.
